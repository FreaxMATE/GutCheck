Build from source

Requires Flutter 3.41+. Clone the repo, fetch dependencies, and run.

terminal 
# 1. Clone
git clone https://github.com/FreaxMATE/GutCheck.git
cd GutCheck

# 2. Install dependencies
flutter pub get

# 3. Generate Isar types + localizations
flutter gen-l10n
flutter pub run build_runner build --delete-conflicting-outputs

# 4. Run (desktop, mobile, or web)
flutter run
